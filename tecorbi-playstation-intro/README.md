## طريقتان للتشغيل الفوري:

### الطريقة الأولى: تشغيل ملف الـ GLB محلياً عبر Three.js `GLTFLoader` (الأفضل للأداء الكامل)
1. من صفحة الموديل على Sketchfab اضغط **Download 3D Model** واختر صيغة **GLB** (سيتم تنزيل ملف باسم `playstation_5_dualsense.glb`).
2. ضع الملف داخل مجلد المشروع في المسار:
   - `public/models/playstation_5_dualsense.glb`
   - أو `public/models/dualsense.glb`
   *(الكود يتعرف تلقائياً على الاسمين فور التشغيل)*، أو اسحب الملف وأفلته مباشرة داخل المتصفح.

**"تشغيل الموديل مباشرة عبر Sketchfab 3D API"**
